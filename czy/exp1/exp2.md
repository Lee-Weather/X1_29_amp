> **核心教训**：
> 1. **证明**：①稳定性回退的归因在策略侧，且可确定性复现（对照实验逐项一致）；②后仰是失稳链条的**上游**——它领先速度 300ms、在 episode 内单调加深，而 exp1.13 新增的姿态终止（31→69）100%/85% 是后仰，即**上轮放大的正是该模式**；③`double_support_k` 0.25 应撤销。
> 2. **否定**：①"加宽双支撑 = 提升稳定性"（k 0.25 使姿态终止翻倍、后仰加深 −0.161→−0.190）；②**单环境回放可作为稳定性验收**（其 h_min 0.520→0.587、roll p95 0.127→0.114 显示"改善"，多环境却是回退）；③后仰是偶发事件（实为**跨代单调恶化的稳态步态特征**）；④此前"腾空×roll 正反馈"的因果层级需上移一层（腾空是链条中段表现，后仰是驱动）。
> 3. **待解决**：策略**能观测到** pitch（actor 观测含 `base_euler_xyz`，obs_scale 1.0）却仍维持约 −0.15 后仰 → **是奖励结构问题，不是感知问题**。pitch 的**瞬时**分量其实已被 `orientation` 覆盖，但该量级只有步态类奖励的 1/3~1/7（实测 `orientation` 0.444 vs `foot_place` 1.58 / `stand_still` 1.47 / `foot_height` 1.43 / `feet_contact_number` 1.17），且用 `exp(−10·|euler_xy|₁)` 与 roll 混算、不可单独调 → 需要一个显式、可调、针对**持续偏移**的新约束。
> 4. **观测口径缺口**：预算表只存 `pitch_max`（**绝对值**），符号与漂移全部丢失 → 后仰在历轮指标里不可见，这是该问题长期未被发现的原因；本轮验收必须依赖新口径。

### 3. 修改内容

#### 修改一：撤销 `double_support_k` 0.25 → 0.1 —— ✅ 已实施

| 参数 | 旧值 | 新值 | 说明 |
| --- | --- | --- | --- |
| `rewards.double_support_k` | 0.25（钟上 DS 16.09%） | **0.1**（钟上 DS 6.38%） | 回到 exp1.12 口径 |

**理由**：exp1.13 的对照实验已证 k 只作用于奖励、不进入回放动力学；k=0.25 使姿态线终止 31→69（2.2x）、后仰由 −0.161 加深到 −0.190，属**已证有害项**。本轮先撤销，避免它成为新变量的混淆项（保证 exp2.0 相对 exp1.12 基线的差异只来自"新增俯仰约束"）。

#### 修改二：新增"持续后仰"约束 `torso_pitch_lpf`（核心）—— ✅ 已实施（参数按实测校准）

| 参数 | 旧值 | 新值 | 说明 |
| --- | --- | --- | --- |
| `scales.torso_pitch_lpf` | — | **1.5**（快测定，初值） | 新增奖励项权重 |
| `rewards.pitch_lpf_alpha` | — | **0.99**（τ≈1.0s） | EMA 低通。**由实测频谱定**：行走段 pitch 能量 <0.1Hz 14.8% / 0.1–0.3Hz 33.0%（慢漂移，要保留）/ 0.5–1Hz 21.8% / 1–2Hz 8.4%（步态摆动，要滤掉）。α=0.95 在 0.5Hz 仅衰减到 0.85、1Hz 0.63 → **等于没低通**；α=0.99 为 0.1Hz 0.85 / 0.5Hz 0.31 / 1Hz 0.16，且对 0.03 rad/s 漂移仅滞后 0.03 rad |
| `rewards.pitch_target` | — | **0.0** rad | 目标躯干俯仰（直立；可调为小前倾 +0.02） |
| `rewards.pitch_sigma` | — | **8** | 核宽。**不用 20**：本核是 `|d|` 形式（非 tracking 的 `‖e‖²`），σ=20 在 d=0.15 处梯度仅 1.0/rad、d=0.25 处仅 0.13/rad —— 而基线后仰恰落 0.15~0.25，等于在唯一需要的区间饱和；σ=8 时该区间梯度仍有 1.94/1.08 /rad |
| `rewards.pitch_lin_coef` | — | **0.2** /rad，cap **0.5** | **线性底**系数与截断（本仓惯例，见理由 3） |

**形式**（每控制步，**指数 + 线性底**，与 `_reward_ref_joint_pos` / `_reward_hip_ref` 同构）：

```python
pitch_lpf = alpha * pitch_lpf + (1 - alpha) * pitch                 # 状态量，reset_idx 清零
d = |pitch_lpf - pitch_target|
r_torso_pitch_lpf = exp(-sigma * d) - lin_coef * clamp(d, 0, cap)   # 只惩罚"持续"偏移
```

**理由**：
1. 用**低通后的 pitch** 而非瞬时 pitch —— 正常步态每步都有俯仰摆动（实测约 0.05 rad），瞬时惩罚会误伤步态节律；低通后只保留"持续后仰"这一实测签名（§1 证据 2 的"段内持续加深"）。pitch 的瞬时分量 `orientation` 里已有，不需要再写一遍。
2. 直接对准失稳链条上游，而不是继续在"腾空/双支撑"等下游表现上加码（§1 教训 2④）。
3. **必须带线性底**：纯 `exp(−20·d)` 在基线后仰 d=0.15 处已饱和——`exp(−3)=0.050`，梯度只有 `20×0.050=1.0/rad`，乘权重与 dt 后 ≈0.015/步，而同量纲的 `tracking_lin_vel` 是 ≈0.079/步，**梯度被压掉 5 倍**，等于没加。线性底给出与偏移量**无关的恒定梯度**（`0.2 × 1.5 = 0.3/rad`），正是纠正"持续偏置"所需的形状；本仓 `_reward_ref_joint_pos`、`_reward_hip_ref` 已是此惯例。
4. 权重取与步态类同量级（`foot_place` 1.58 / `foot_height` 1.43），避免又出现"量纲淹没"（exp1.2 的历史教训：style 上限 0.015 vs task O(6)）。

#### 修改三：~~`orientation` 拆分出独立 pitch 项~~ → **本轮不做**

| 参数 | 结论 |
| --- | --- |
| `scales.orientation` / 新增 `orientation_pitch` | **保持现状（1.2，roll+pitch 混合）不动** |

**不做理由**（已评估，留档避免重复讨论）：
1. **功能重叠**：pitch 的瞬时分量 `orientation` 已覆盖；修改二新增的是它没有的"持续分量"。再拆一个瞬时项属重复，且瞬时项会误伤步态周期内的正常俯仰摆动。
2. **扰动已收敛项**：`roll` 逐代在改善（0.261→0.140→0.127→0.114，§1 跨代表），拆分需重算 roll 权重，属无收益的风险。
3. **可调性可由新项满足**：修改二的 `scales.torso_pitch_lpf` 已独立可调，`orientation` 不必动。
4. **降级为 exp2.1 备选杠杆**：若修改二权重加倍仍压不住后仰，再启用"拆 orientation + 提 pitch 权重"作为第二代手段（单变量追加，不首轮捆绑）。

#### 修改四：观测口径修复（零成本，先于训练执行）—— ✅ 已实施

| 新增字段 | 定义 |
| --- | --- |
| `walk_pitch_mean` | 行走段（cmd_x>0.05）pitch 均值（**带符号**）= 全程水平 |
| `walk_pitch_start` | 各行走片段**首 1.0s** 的 pitch 均值（= "起步姿态"） |
| `walk_pitch_slope` | 各**完整行走片段整体最小二乘**斜率（**rad/s**，负=越来越后仰），跨片段取均值 |
| `walk_pitch_span` | 各片段 `末 pitch − 首 pitch`（rad，负=越走越后仰）的跨片段均值 |
| `pitch_signed_{2000,1000,500,100}ms` | 各尺度窗口的**带符号** pitch 均值（原 `apitch_*` 只存绝对值） |
| 报告端 ⑨ 节 | 上列分位 + 按终止原因分解 + `pitch_end` 方向偏置 + **"后仰+反向"终止占比** |

**实施要点（含踩坑记录）**：
1. **必须按行走片段各自拟合**，不可跨片段整段拟合一个斜率——一个 episode 会跨多次命令重采样，跨片段拟合会被污染（§1 证据 7）；实现上利用"片段内掩码恒真"→ `t = 0..n−1`，Σt 与 Σt² 有解析式，只额外累计 `Σt·p`。
2. **单位陷阱**：回归天然得到 rad/**控制步**，必须 ×(1/dt) 转 rad/s（首版漏转，读数被缩 100 倍）。
3. **直线斜率会低估加深量**：实测段内轨迹**非单调**（先深后回），回归斜率中位仅 −0.006 rad/s，而同组片段首末跨度中位 **−0.208 rad（≈12°）** → 故并列输出 `span` 与"水平法"（`mean − start`）互为对照。
4. `pitch_end` **原本就是带符号的**，无需新增（历轮报告未用它做方向分析）。

**零成本实测（512env×3ep，exp1.12 底模）**：脚本跑通、字段齐备 → 见 Step 0 产物 `czy/analysis/exp2.0/`。

**理由**：不留这一项，下一轮仍无法判断"后仰是否被治好"；§2 的目标1、目标2 全部依赖它。**附带收益**：pitch 判据从"单环境回放"（env0 单次抽取，§21h 证其结论偏差可达 40%）升级为 **512 环境分布判据**。

**早期实测已独立复现核心结论**（小幅 64env 验证）：行走段起始 pitch ≈ **−0.04 rad（近乎直立）**，段末比段首再后仰 **0.21 rad** → **"后仰"主要是行走过程中的累积（drift），不是起步姿态**，与 §1 证据 2（段内持续加深）一致，也解释了为何只看 `|pitch|max` 的历轮指标抓不到它。

> · exp1.13：姿态终止 31→**69**、h<0.45 167→169（持平）→ 净 15.2%
