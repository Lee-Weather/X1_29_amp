## 一、a 为什么前进不动

### 1. 不前进仍有正收益，已由逐项奖励确认

下表均为名义模式、每段去掉首秒后的 400 个采样。奖励统一除以 dt=0.01，表示 **AMP 融合前任务回报率**；行走实际只取其中 0.5。

| 指标 | +0.4 指令 | +0.6 指令 |
| --- | ---: | ---: |
| 实际 vx | +0.0132 m/s | −0.00047 m/s |
| 双脚同时接触比例（各脚 Fz>5 N） | 97.25% | 100% |
| 速度误差惩罚 | −1.547/s | −2.402/s |
| foot_height 正回报 | +1.336/s | +1.334/s |
| tracking_ang_vel 正回报 | +0.999/s | +1.048/s |
| 合计任务回报 | **+2.267/s** | **+1.297/s** |

`foot_height` 每脚给指数正奖励，走不起来也能拿到较大部分；角速度、姿态、距离等收益共同抵消速度成本。这里没有误触发站立奖励：这两个窗口 `stand_still/default_joint_pos` 均为零。是行走任务内部存在“保持静止也划算”的组合。

### 2. 方向门控让原地策略几乎拿不到 AMP 起步信号

代码用 `clamp(sign(cmd)*EMA(vx)/abs(cmd),0,1)`。a 的 +0.6 窗口 gate 约 0.0081，融合 style 仅 0.00000396/步。训练曲线也显示 a/b 行走 style 占比约 0.64%/2.37%，D(agent/demo) 约 −0.997/+0.996。门控与容易区分的判别器共同让实际模仿约束很小。

这是支持“原地局部最优”的证据，不是已完成的单项因果消融。提高 AMP scale 不能直接修复接近零的 gate，也不能保证修复 D 分离。

### 3. 行走时的横向关节及航向约束偏弱

exp3.1 将旧 `default_joint_pos` 限为站立；行走剩余 `hip_ref` 只约束两侧 hip pitch，全身 29 维 L2 指数奖励在误差较大时降到很弱的量级。a 全段参考 L2 均值 1.407 rad，右髋 yaw RMS 误差 0.651 rad，累计航向偏移 65.6°。

父环境在指令换段时刷新 `_yaw_ref`，连续直行任务允许分段累积偏航，是另一项应修正的机制；本次未单独量化其因果贡献。旧默认髋 yaw 为左 −0.31 / 右 +0.31 rad，不能直接把旧行走默认姿态约束恢复为强约束，否则与新参考冲突。

## 二、b 为什么起步约 1 s 就倒

### 1. 短暂达到速度，不等于形成步态

首次名义 +0.4 起步窗口 5.05–6.14 s：平均 vx=+0.4004 m/s，但双脚接触比例仍有 80.91%，任务回报 +4.078/s。随后：

| 时间 | 高度 | pitch | vx |
| --- | ---: | ---: | ---: |
| 5.20 s | 0.596 m | −0.4° | +0.370 m/s |
| 5.80 s | 0.550 m | +1.2° | +0.457 m/s |
| 6.00 s | 0.503 m | +16.7° | +0.580 m/s |
| 6.15 s | 0.473 m | +47.2° | +0.331 m/s |

高度先明显下降，俯仰随后快速发散；更像身体产生了前向运动，却没有建立持续的交替支撑。双脚接触率本身不证明拖脚，需结合脚高、滑移和视频判断。名义、随机域首次终止为 6.15/6.12 s，故完整随机域会加难，但不是唯一原因。

### 2. PD 位置目标越过关节范围，值得优先修复

`legged_robot.py::_compute_torques` 当前按 `action*0.3+default+motor_offset` 产生目标。入口 action 限幅 ±3，只限制统一偏移 ±0.9 rad；没有按每个关节上下限限制目标。

首次起步窗口 110 个采样中：**右踝 pitch 的延迟后位置目标有 102 次超出 URDF 范围，最大超出 0.700 rad**；左踝目标也最大超出 0.299 rad。a 同样有多关节目标越界。这是目标不可达的直接证据，会造成持续位置误差，并可能使控制行为偏向关节边界；尚未证明它单独导致跌倒。

CSV 的 `pos_des_raw` 是最后一个物理子步的延迟后目标、尚未加入 motor_offset，不是实测角度；名义模式 offset 为中心值。首次起步窗口共 49 次关节×物理子步力矩限幅事件，不能因为末子步力矩未限幅就说全程无限幅，也不能据此断言全部由力矩饱和引起。现有证据不足以直接改大 PD 增益或电机力矩。

### 3. 姿态奖励主要是“失去奖励”，缺少提前惩罚

高度和 orientation 以指数正奖励为主，偏离后接近零；到 h<0.45 m 或 |roll/pitch|>0.8 rad 才终止。首次起步速度对时仍得到正任务收益，说明速度回报与支撑稳定性没有充分绑定。

从零初始动作 std=1.0、reset 有 50% 直接行走、完整随机域/噪声，会增加学习难度。这些为代码支持的训练难度假设，尚未做消融；不能盖过名义确定性回放也失败的事实。

## 三、建议的 exp3.2 主方案

参考继续使用 v1.2 B3/B4，示范采样 1:1，任务仍为站立、前进、后退。**优先级 P0 的三组修改一起构成主方案；P1 留作后续独立对照。** 数值是有依据的首版候选，提交训练前还需核对奖励预算和边界行为。

### P0-A：保证控制目标可达

- 在独立 exp3.2 环境的 PD 路径中，延迟和 motor_offset 合成后，按每个关节的软位置范围限制最终目标；软范围从真实上下限两侧各留 2% 余量，检查所有参考/默认姿态均在允许范围内。
- 保持原动作定义、action_scale、PD 增益及力矩上限。不要把新参考直接叠加到旧残差动作上，避免同时改变整个控制参数化。
- 记录原目标、最终目标、每关节越界幅度/限幅率和各子步力矩限幅。若长期卡在边界，继续解决策略输出与参考约束，不能只靠裁剪遮住问题。

### P0-B：消除原地正回报，给模仿保留起步信号

| 参数 | exp3.1 | exp3.2 首版候选 |
| --- | --- | --- |
| signed_speed_error scale | 4 | 8 |
| foot_height scale | 1 | 0.25 |
| AMP style scale / task lerp | 5 / 0.5 | 暂沿用 5 / 0.5 |
| 正 style 方向门控 | 原地为 0 | 原地/方向正确时下限 0.2；明确反向时平滑降到 0 |

门控候选：令 s=sign(cmd)*EMA(vx)，p=clamp(s/max(abs(cmd),0.1),0,1)，g=max(0.2,p)*clamp((s+0.08)/0.05,0,1)。因此 s≥−0.03 m/s 有启动底值，s≤−0.08 m/s 无正风格奖励，区间平滑过渡；站立、终止仍不奖励 style，负 style 不被门控抹掉。新门控允许小范围反向噪声，需用实际反向收益检查漏洞。

离线重算原记录轨迹，仅调整速度和 foot_height 两项：a 的 +0.4/+0.6 task 从 +2.267/+1.297 变为 **−0.282/−2.105 每秒**；单把速度改 8，+0.4 仍为 +0.720/s。b 首次起步仍为 **+3.046/s**，再次说明必须同时补稳定约束。这些是固定轨迹的重计分，不是新策略的实验成绩。

训练前需比较“健康行走、原地、反向、跌倒”的累计回报，包括折扣与 reset 后站立收益；只把原地改负可能诱发提前结束来逃避负回报。终止尺度当前 −100（行走融合后仅 −0.5/次）也应纳入该预算，再确定是否增加，不能只看单步收益。

### P0-C：加强参考姿态和连续稳定性约束

- 用按关节组归一化的 Huber 误差替代单一 29 维 L2 指数跟踪项。髋 roll/yaw、踝 roll 独立一组，腿 pitch/knee 一组，上半身一组；跟踪当前速度、相位与站走混合后的 v1.2 目标。各组平均，避免上半身关节数淹没腿部错误。容差候选 0.2/0.35/0.4 rad，组权重候选 2/1/0.2，均作为负成本，按 dt 统一缩放。
- 躯干 roll/pitch 相对参考增加超过 0.1 rad 后的连续负成本；平地高度在低于 0.55 m 时提前惩罚，并以参考高度分布核对安全范围。现有 0.45 m、0.8 rad 硬终止线保持。
- 直行任务的目标航向只在 episode 开始建立，站走/正反向切换不刷新；加入环绕航向误差成本，保留原角速度惩罚。若后续添加转向任务再重新设计目标。
- 增加摆动相单脚离地、落脚接触与滑移的分项诊断。不要强制所有相位单脚支撑，保留正常双支撑过渡；先检查 foot_height/feet_rotation 的脚坐标定义及参考一致性。

### P1：主方案仍学不动时的单独对照

1. reset 先站稳 1 s，前 1000 轮指令用 0.3 s 斜坡，之后逐步恢复完整跳变；训练和回放明确记录 requested/applied/observed。最终验收仍使用原始六段阶跃，不用缓变回放掩盖起步问题。
2. 初始动作 std 候选 0.5；随机域前期围绕已验证训练中心缩窄，3000 轮前恢复 exp3.1 完整范围。使用同一套动力学基线，不能简单关闭 DR 退回另一组 URDF 阻尼参数。
3. 若 pose 已改善但 D 仍近乎完全分离，再单独研究 D 更新频率、正则化及示范/agent 支持域；若改变为指令条件判别器，必须同时匹配示范与 agent 的指令采样分布。这不是本轮第一优先项。
