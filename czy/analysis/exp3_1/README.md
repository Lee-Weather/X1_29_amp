## 关键实现

- 仅使用 v1.2 B3/B4，AMP 示范权重仍为 1:1；站立走 task 回报。
- 风格尺度 100 → 5；正风格按平滑后的带符号前进程度门控，保留行走状态中的负风格成本，终止步屏蔽风格项。
- 保留负 task，新增连续带符号速度误差，加入终止成本；关闭 foot_place/low_speed，修正脚滑移为水平线速度。
- 关节与骨盆 roll/pitch 参考使用相同相位和 0.3 s 起停混合；行走期间关闭默认姿态项。
- 新环境按 URDF 基准重算每次关节随机属性，修复 friction/damping 跨复位累乘。
- 指令在 policy 前注入；训练中下一指令在本步奖励之后采样。回放保存终止前快照、请求/实际/观测指令、回报分项及逐物理子步限幅累计。
- `nominal_no_push` 固定其他随机范围为训练中心；`randomized_no_push` 保留训练随机域和噪声。两者关闭推力。
- 每两个控制步输出一帧，当前视频 50 FPS；默认六段共 30 s。元数据记录实际 checkpoint 路径、seed、评测模式和 reset 次数。
