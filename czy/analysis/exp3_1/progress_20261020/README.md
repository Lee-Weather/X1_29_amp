## 已证实的训练瓶颈

### 1. 有效 AMP 风格信号已经很弱

`amp_style_reward_scale=5` 并不等于实际风格占比 5%。风格经历 D 评分、dt、尺度、正风格方向门控和 0.5 融合系数后，实际贡献分别只占约 0.64% / 2.37%。两组 D 都几乎将 agent 判为 −1、demo 判为 +1，说明两类动作分布仍然容易区分，低 D loss 不代表策略已经接近示范。

尺度降至原来的 1/20 旨在解除旧实验风格主导，但本轮又叠加方向门控和 D 评分接近 −1。实测提示尺度 5 对从零组可能过弱；目前 PPO 主要依靠离散的任务塑形项学习，示范对稳定步态的约束不足。这是有日志支持的瓶颈，**尚未通过单变量消融证明它是全部提前终止的唯一原因**。不能据此直接恢复到旧尺度 100。

### 2. 从零组的探索强度和学习难度明显更高

b 的策略动作标准差约为 a 的 2.53 倍；平均标准差之比对应的平方约为 6.4，但不是逐关节精确方差比。b 的 episode 更短，`Episode/rew_action_smoothness` 反而更负（−0.1928 对 −0.1599，使用相同 24 s 归一化），符合动作更粗糙、探索更强的状态。

本轮只关闭推力，仍保留 COM 各轴 ±5 cm、底座质量 ±3 kg、增益/电机强度 0.8–1.2、观测噪声 1.5、动作延迟 5–40 ms 和关节观测延迟 0–40 ms 等随机项。b 没有从较容易的动力学逐步过渡到这些范围。a 继承 085 的运动能力，b 需要同时学落地、平衡、正反向行走和停步。

### 3. 站立与行走的奖励及起步难度仍不平衡

站立使用完整 task，行走使用 0.5×task+0.5×style；style 几乎消失后，行走只剩半份任务回报，站立仍有 `stand_still=3.5` 等密集正奖励。切换到行走后增加连续速度成本，默认姿态项归零，同时需要完成抬腿、跟速与平衡。

此外，50% reset 批次直接获得行走指令，出生高度 0.7 m，关节从默认角度 ±0.1 rad 采样；新策略可能在落地/起步阶段就失败。另一半先站立。`gait_time_range` 不是固定秒数执行，而是被 `generate_gait_time` 按 24 s 总长重新缩放：初始站立段理论约 4.24–8.57 s。b 的 4.52 s 平均寿命与“起步/行走能力仍未建立”的假设一致，但日志没有按 stand/forward/backward 分类的终止率，不能仅凭均值认定具体在哪个阶段倒下。

## 后续处理

按用户既定安排完成两组本次 6000 轮，保留初始化对照。当前平台没有异常退出或 NaN 的证据。

优先对相邻 checkpoint 做确定性回放：站立、+0.4、+0.6、−0.2 及六段序列；分别使用 `nominal_no_push` 与 `randomized_no_push`，统计终止时刻/原因、所属命令段、真实 vx、足接触和 ref 误差。名义模式也失败时先查参考与动作/平衡；名义正常而随机域失败时优先做随机域课程。

若回放支持步态约束不足，再保留方向门控、小幅提高 style 尺度进行消融，并按实际贡献校准；从零组同时考虑更温和的初始动作探索、落地/站立到行走的课程。当前不据这些推断在运行中的任务上改参。
